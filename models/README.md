# Trained Models

The trained deep learning model files are not included in this repository because they exceed GitHub's 100 MB file size limit.

Download the models from:

https://drive.google.com/drive/folders/1c7sJhtEi0wtUPFW6KmITYjCwJP7fu4M2?usp=sharing

After downloading, place all `.keras` model files in this folder.

Required models:

- tbnet_final.keras
- resnet50_v2_final.keras
- densenet121_final.keras
- efficientnetb4_final.keras
- custom_cnn_final.keras
